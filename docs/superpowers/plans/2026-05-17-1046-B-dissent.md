# #1046 Slice B — Company-Rest Dissent Flow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) tracking.

**Goal:** Give the player (and bot-player) a recourse when C2's chartered company doctrine forces a lay-by — a unified pausable dissent modal (Abide / Override-or-Lobby by captaincy / Press-on-solo) — and wire `shouldDissent` so the sweep can measure whether the dissent valve claws back C2's governance-only −8..−17pp arrival drop.

**Architecture:** The choice is recorded on C2's `companyDecisionBlock` as `dissentChoice` (sticky per decision block, exactly like C2's hysteresis state). `tickDayPausable` pauses with `_companyDissentPending` when the company forces a `*_layby` and no choice is recorded yet (mirrors the #936 MudAbandon pause/resume); a pure `resolveCompanyDissent` applies the choice; the bot-player consults `persona.shouldDissent` so the sweep exercises it. Press-on-solo calls the existing `leaveTrain` + sets a re-join cooldown.

**Tech Stack:** TypeScript, Vitest, SvelteKit. VCS = **jj** (not git). Branch: `feat/1046-B-dissent` (already created off the C1+C2+#1056-merged master).

```ts
const OVERRIDE_MORALE_COST = 5;
const LOBBY_FAIL_MORALE_COST = 2;
const LOBBY_BASE_CHANCE = 0.35;
const LEFT_TRAIN_COOLDOWN_DAYS = 10;

export type DissentChoice = 'abide' | 'override' | 'lobby' | 'press_on';

export function dissentTrigger(state: GameState, companyMode: CompanyRestMode): boolean {
  const block = state.wagonTrain?.companyDecisionBlock;
  if (!state.wagonTrain || !block) return false;
  // Dissent is for DOCTRINE lay-bys only (maintenance / Sabbath). A
  // crisis_layby is the doctrine-independent universal safety floor
  // (spec §4 "even a hard-driver stops") — the player cannot "press
  // on" while a member is near death, and C2 contractually advances
  // the day on it. Never prompt on travel or crisis.
  if (companyMode === 'travel' || companyMode === 'crisis_layby') return false;
  return block.dissentChoice === undefined;
}

export function resolveCompanyDissent(
  state: GameState,
  choice: DissentChoice,
  rng: Rng
): GameState {
  const train = state.wagonTrain;
  if (!train || !train.companyDecisionBlock) return state;
  const block = train.companyDecisionBlock;
  const setChoice = (
    c: NonNullable<typeof block.dissentChoice>,
    extra: Partial<GameState> = {}
  ): GameState => ({
    ...state,
    ...extra,
    wagonTrain: { ...train, companyDecisionBlock: { ...block, dissentChoice: c } }
  });

  if (choice === 'abide') return setChoice('abide');

  if (choice === 'press_on') {
    const left = leaveTrain(state);
    return {
      ...left,
      flags: { ...left.flags, _leftTrainCooldownUntilDay: state.day + LEFT_TRAIN_COOLDOWN_DAYS }
    };
  }

  if (choice === 'override') {
    return setChoice('override', {
      morale: Math.max(0, state.morale - OVERRIDE_MORALE_COST),
      eventLog: [...state.eventLog,
        { day: state.day, text: `You overruled the company's lay-by. (−${OVERRIDE_MORALE_COST} morale)` }]
    });
  }

  // choice === 'lobby' (NPC captain). Devout never skips the Sabbath.
  if (train.doctrine === 'devout' && isSunday(state.date)) {
    return setChoice('lobby_fail', {
      morale: Math.max(0, state.morale - LOBBY_FAIL_MORALE_COST),
      eventLog: [...state.eventLog,
        { day: state.day, text: `The captain will not break the Sabbath, whatever you say. (−${LOBBY_FAIL_MORALE_COST} morale)` }]
    });
  }
  const moraleBonus = (state.morale - 50) * 0.005;
  const priorFails = (state.flags._failedLobbyCount as number | undefined) ?? 0;
  const failPenalty = priorFails * 0.05;
  const stubborn = train.doctrine === 'hard_driver' ? 0.10 : 0;
  const threshold = LOBBY_BASE_CHANCE + moraleBonus - failPenalty - stubborn;
  if (rng.chance(Math.max(0, threshold))) {
    return setChoice('lobby_ok', {
      eventLog: [...state.eventLog,
        { day: state.day, text: `Your appeal carried — the captain calls a travel day.` }]
    });
  }
  return setChoice('lobby_fail', {
    morale: Math.max(0, state.morale - LOBBY_FAIL_MORALE_COST),
    flags: { ...state.flags, _failedLobbyCount: priorFails + 1 },
    eventLog: [...state.eventLog,
      { day: state.day, text: `The captain refused your appeal. (−${LOBBY_FAIL_MORALE_COST} morale)` }]
  });
}
```

/** #1046 B — resume a dissent pause. Tail-only continuation (mirrors
 *  applyPendingChoice): the daily systems already ran in the paused
 *  tickDayPausable, so this resolves the choice then ONLY finishes the
 *  day (travel-if-the-company-moves, fire, death, advanceTrain,
 *  day-advance). Never re-runs progressConditions/consumption/etc. */
export function applyCompanyDissent(
  state: GameState,
  choice: import('./systems/company-rest').DissentChoice,
  rng: Rng
): GameState {
  let s = resolveCompanyDissent(state, choice, rng);
  // Clear the pending flag (consumed).
  s = { ...s, flags: { ...s.flags, _companyDissentPending: undefined } };

  // Effective company-travel for the day from the resolved outcome:
  // override / lobby_ok → the whole company breaks camp (travel);
  // abide / lobby_fail → lay by (no miles); press_on → train is now
  // null and the party pushes on alone (solo travel).
  const dc = s.wagonTrain?.companyDecisionBlock?.dissentChoice;
  const travels = !s.wagonTrain                 // press_on left → solo travel
    || dc === 'override' || dc === 'lobby_ok';

  if (travels) s = applyTravel(s, rng);
  s = attemptFire(s, rng);
  s = reapDead(s, rng);
  const trainResult = advanceTrain(s, travels);
  s = trainResult.state;
  return { ...s, day: s.day + 1, date: advanceDate(s.date) };
}
